# Каэль Морвейн — павший рыцарь Бездны

Третий герой ECHO. Канон и поведение — по спецификации автора.

## Канон

- Чёрные волосы, **глаз Бездны** (фиолетовый, со шрамом) — левый.
- **Механическая рука** (левая): чёрная сталь + фиолетовые руны/трещины, сегменты
  перестраиваются, из соединений может вырываться багрово-фиолетовое пламя.
- **Рваная багровая накидка**, чёрная броня, коричневые ремни, символ Бездны.
- **Спутник — утконос**: ходит рядом, ложится у ног, чувствует опасность первым.
- Оружие **«Разлом»** — трансформирующийся клинок в трёх формах:
  - *походная* — узкий прямой клинок (idle, работа, просмотр, отдых, уход);
  - *мечевая* — изогнутый боевой клинок (игра, победы, поиск, быстрый бой);
  - *полная* — коса с крюком (серия побед, уровень, длинная сессия, «Шов Бездны»).

Трансформация функциональна, а не декоративна: форма всегда говорит, что происходит.
Визуальный канон трёх форм сохранён в [`docs/reference/kael-razlom-weapons.png`](docs/reference/kael-razlom-weapons.png).
Оружие не появляется в сцене органа: там работают только обычная и механическая руки.

## Поведение

| Триггер | Сцена | Клип |
|---|---|---|
| Покой | Спокойное дыхание, движение шарфа и слабый импульс механической левой руки | `idle_v2` |
| Редкий idle | Правой рукой поправляет шарф и точно возвращается в idle | `scarf_adjust` |
| Проверка руки | Вращает левую кисть, замечает малый сбой и подавляет его правой рукой | `armcheck_v2` |
| Утконос | Короткое спокойное взаимодействие без смены стойки | `platypus_v2` |
| Печать | Опускается на колено, работает с малыми рунами и затем встаёт | `work_enter` → `work_loop_v2` → `work_exit` |
| Долгая работа | Та же связная рабочая поза, но loop удерживается дольше | `work_enter` → `work_loop_v2` → `work_exit` |
| Поиск | Компактный импульс Бездны без большого портала | `search_v2` |
| Успех | Маленькая сфера превращается в знак Бездны, гаснет в кулаке; один кивок | `success_v2` |
| Ошибка | Сбой в левой руке, захват запястья правой рукой и контролируемое восстановление | `error_v2` |
| Серия ошибок | Усиленный, но локальный сбой без падения и телепортации позы | `overload_v2` |
| Запуск или восстановление игры | Один раз раскрывает «Разлом» из походной формы в меч | `weapon_draw_sword` |
| В игре | Живая боевая стойка без ходьбы на месте | `combat_idle_v2` |
| Серия успехов | Удар мечевой формой и точный возврат в combat idle | `streak_v2` |
| Долгая сессия | Меч временно раскрывается в полную форму-косу и возвращается в меч | `fullweapon_v2` |
| Завершение игры | Один раз складывает меч в походную форму | `weapon_draw_sword` назад |
| Видео | Садится спиной, слегка поворачивает голову к центру дисплея | `watch_enter_v3` → `watch_loop_v3` → назад |
| Короткое отсутствие | Садится рядом с утконосом и возвращается той же цепью | `rest_enter` → `rest_loop_v2` → назад |
| Долгое отсутствие | Полностью уходит через разлом; после прозрачного кадра окно скрывается | `leave_v2` |
| Возвращение | Окно появляется у края, сначала выходит утконос, затем Каэль | `return_v2` |
| Ночь (00:40, catch-up до 04:59) | Сидячая стража у разлома-зеркала и редкий взгляд в сторону пользователя | `night_enter_v2` → `night_loop_v2` / `night_glance_v2` → назад |

Все клипы проигрываются в авторском темпе `1.0`. Runtime хранит режим
`idle/work/watch/combat/night/away/scene` и форму оружия `dormant/sword/scythe`.
Циклический клип не запускается без активного режима, а работа, просмотр и отдых
всегда имеют отдельный вход и выход. Шаги связаны с реальным движением окна со
скоростью около 125 px/s; полный цикл ног длится 1,26 с, а на контактных кадрах стопы окно лишь мягко замедляется.

## Орган Бездны — 47 секунд

Музыка: **Guy Bovet & Иоганн Себастьян Бах — Passacaglia and Fugue in C Minor**
(`public/media/kael-passacaglia.mp3`). Перед публичным релизом нужно подтвердить
право распространять именно эту запись.

Первые 11 секунд сцены идут без музыки. Трек запускается точно на первой
играющей позе после того, как Каэль сел и орган полностью собран.

Глобальная горячая клавиша **Alt+S** запускает эту сцену для активного Каэля. Она
не добавляет пользовательскую кнопку управления и не прерывает уже идущую сцену.

| Время | Действие | Клип |
|---|---|---|
| 0:00–0:05 | Глаз Бездны светится, сегменты левой руки раскрываются, утконос смотрит | `organ_sense_v2` (loop) |
| 0:05–0:11 | Касание поверхности, трещина, сборка клавиш и труб, Каэль садится | `organ_summon_v2` |
| 0:11–0:31 | Обе руки играют, плечи следуют ритму, руны и трубы пульсируют | `organ_play_v2` (seamless loop) |
| 0:31–0:39 | За трубами постепенно проявляются три рыцаря ордена | `organ_memory_v3` |
| 0:39–0:43 | Утконос нажимает педаль, Каэль коротко смотрит на него | `organ_platypus_v2` |
| 0:43–0:47 | Последний аккорд, орган растворяется позади видимого Каэля, затем физический подъём в idle | `organ_fade_v3` |

## Главная ежедневная сцена — «Шов Бездны» (`kael_voidstitch`)

Ответ Каэля на ту же угрозу, что у Корвина, но принципиально другим способом:

1. Утконос бьёт хвостом по панели — тревога.
2. В нижнем углу экрана появляется чёрная трещина.
3. Каэль вонзает механические пальцы в край и фиксирует её.
4. «Разлом» раскрывается из мечевой в полную форму.
5. Из трещины лезут длинные теневые пальцы.
6. Он цепляет разрыв крюком и стягивает края.
7. Механическая рука выпускает серебристые рунические нити.
8. Зашивает трещину крест-накрест.
9. Последний узел прижигает багровым пламенем.
10. Глаз остаётся чёрным несколько секунд — цена.
11. Утконос касается сапога, глаз возвращается в норму.

В runtime это непрерывная цепь `voidstitch_alarm` → `voidstitch_pull` →
`voidstitch_seal`. Контактные кадры между частями совпадают пиксель в пиксель.

## Внутренняя визуальная проверка

- `kaelreview` последовательно показывает новый набор Каэля, кроме уже
  одобренной 47-секундной сцены органа.
- `videoreview` показывает вход, живой loop и выход из просмотра для Данте,
  Корвина и Каэля, после чего возвращает исходного героя.
- `fullreview` объединяет video review, old/new reel Данте, Door/night Корвина и
  связанный набор Каэля; одобренная 47-секундная organ-сцена остаётся отдельной.
- `Alt+S` запускает орган Каэля и после сцены восстанавливает sword-state, если
  игровая сессия всё ещё активна.

Это QA-триггеры разработчика. В пользовательском меню кнопок управления сценами
нет: просмотр, работа, игры, Director и ночные часы запускаются автоматически.

## Редкая встреча с Корвином (раз в 7–14 активных дней)

- `kael_corvin_visit` — «Старая стража»: сцепляют предплечья, Корвин точит меч,
  Каэль чинит руку, Арцив изучает утконоса и отодвигается, оба почти улыбаются.
- `kael_corvin_breach` — «Спина к спине»: Корвин удерживает существо, Каэль
  закрывает проход. Ещё реже.
