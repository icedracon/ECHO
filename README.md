# ECHO

Живой pixel-art компаньон для рабочего стола. Он стоит у края экрана, реагирует на твою работу, игры, музыку и простои, а в свободные моменты живёт своей маленькой жизнью.

ECHO сейчас включает двух персонажей:

- **Корвин** — молчаливый Страж с белым орлом Арцивом, тяжёлым клинком, историями, ночной гитарой и сценой Двери.
- **Данте** — охотник с Devil Trigger, мечом, пиццей, постером и громкими игровыми payoff-сценами.

Приложение работает локально. В рантайме нет телеметрии и внешних запросов; память, настройки, пользовательская музыка и выбор персонажа лежат в `~/.echo/`.

## Быстрый старт — без команд

1. Открой страницу [последнего релиза ECHO](https://github.com/icedracon/ECHO/releases/latest).
2. Скачай **один рекомендованный файл** для своей системы из таблицы ниже.
3. Открой его обычным двойным кликом. ECHO сам появится у края экрана и останется рядом с часами.

| Твоя система | Скачай этот файл | Что делать после загрузки |
|---|---|---|
| Windows 10/11 | `ECHO-Windows-Setup.exe` | Открыть и пройти короткую установку |
| Fedora / RHEL / openSUSE | `ECHO-Fedora-x86_64.rpm` | Открыть через центр программ и нажать «Установить» |
| Ubuntu / Debian | `ECHO-Debian-x86_64.deb` | Открыть через центр программ и нажать «Установить» |
| Другой Linux | `ECHO-Linux-x86_64.AppImage` | В свойствах файла разрешить запуск как программы, затем открыть |
| Mac с M1/M2/M3/M4 | `ECHO-macOS-Apple-Silicon.dmg` | Открыть образ и перетащить ECHO в Applications |
| Mac на Intel | `ECHO-macOS-Intel.dmg` | Открыть образ и перетащить ECHO в Applications |

Для Windows без установки есть `ECHO-Windows-Portable.exe`: скачай и открой. Файлы `ECHO-Corvin.exe` и `ECHO-Dante.exe` сразу запускают выбранного героя.

### Если система показала предупреждение

ECHO пока не подписан платным сертификатом, поэтому Windows или macOS могут показать предупреждение о неизвестном издателе.

- **Windows:** нажми «Подробнее», затем «Выполнить в любом случае».
- **macOS:** нажми по ECHO правой кнопкой, выбери «Открыть», затем ещё раз «Открыть». Если кнопки нет: System Settings → Privacy & Security → Open Anyway.

После первого появления ECHO покажет, где находится управление. Никакая консоль, аккаунт или настройка не нужны.

## Управление

После запуска рядом с часами появляется иконка ECHO. Правый клик открывает меню:

- **Персонаж** — переключить Корвина и Данте без перезапуска.
- **Сцены** — вручную запустить бой, полёт Арцива, историю, Devil Trigger и другие сцены.
- **Сыграть песню** — также доступно через `Alt+S`.
- **Тихий час** — попросить ECHO не отвлекать.
- **Мои песни и постеры** — открыть папку пользовательских медиа.
- **Как управлять ECHO** — снова показать короткую подсказку.

## Что он умеет

### Корвин

- Несёт вахту у края экрана: плащ на ветру, клинок, медитация, скан периметра.
- Выпускает Арцива: орёл летит поверх окон и возвращается на плечо.
- Рассказывает главы и короткие байки локальным голосом Корвина в темпе 1,5x, помнит прогресс и не повторяется без нужды.
- Реагирует на работу: успехи, провалы, долгие ночи, игры, музыку и отсутствие пользователя.
- В сцене **Двери** отступает настоящими шагами, парирует лапу, поднимает проклятую руку, а тентакли выходят из руки и отталкивают угрозу назад.

- На ошибки может падать с панели и карабкаться обратно.

## Своя музыка и постеры

Открой меню ECHO возле часов и выбери **Мои песни и постеры**. Нужная папка откроется сама на Windows, Linux и macOS.

| Файл | Для чего |
|---|---|
| `nightsong.mp3` | Ночная песня Корвина и ручной запуск через `Alt+S` |
| `sadsong.mp3` | Реквием Корвина |
| `poster.gif` | Постер Данте |
| `song.mp3` | Трек для сцены с постером |

Положи файл с нужным именем в открытую папку и перезапусти ECHO. Готово.

## Для разработчиков и тестирования

Обычным пользователям этот раздел не нужен: все основные действия и сцены доступны мышкой через меню ECHO.

### Запуск из исходников

Windows:

```powershell
.\Start ECHO.bat
```

Режим разработки:

```powershell
.\Start ECHO.bat dev
```

Linux:

```bash
./Start\ ECHO.sh
```

### Демо-команды

Команды пишутся в `~/.echo/demo`.

PowerShell:

```powershell
Set-Content "$env:USERPROFILE\.echo\demo" "door"
```

Bash:

```bash
echo door > ~/.echo/demo
```

Полезные слова: `corvin`, `dante`, `reel`, `fly`, `tale`, `chapter`, `night`, `requiem`, `break`, `breach`, `combo`, `letter`, `road`, `rain`, `cairn`, `execution`, `unchained`, `cleave`, `vigil`, `guitar`, `hunt`, `scan`, `nuzzle`, `damage`, `parry`, `ritual`, `devil`, `sword`, `poster`, `pizza`, `coin`, `spin`, `clean`, `wake`.

### Visual и physics QA

ECHO — 2D pixel-art, но движение проверяется как физика сцены:

- окно персонажа фиксировано в `260x420`: нижние `190px` принадлежат персонажу, верхняя зона — только речи;
- спрайт закреплён снизу справа, пузырь текста держится в верхней зоне и не перекрывает тело;
- обычная ходьба идёт через `slideWindow()` с постоянной скоростью;
- посадка/подъём используют `moveWindowY()` с весом и небольшим overshoot;
- Door backstep использует `stepWindowX()` — короткие рывки по footfall-таймингу, чтобы Корвин не скользил;
- лапа Двери имеет ограниченный reach/lunge, а появление растянуто по времени;
- тентакли сцены Двери привязаны к точке поднятой руки Корвина и каждый кадр дотягиваются до текущей позиции лапы.

Перед релизом запускается:

```bash
npm run verify
```

Эта команда сначала проверяет все кадры, покадровые тайминги, триггеры, решения режиссёра и голосовой пакет, затем собирает web-часть, прогоняет Rust-тесты и делает desktop release build без упаковщика.

### Разработка

```bash
npm install
npm run dev
npm run tauri dev
```

Основные папки:

| Путь | Назначение |
|---|---|
| `src/` | TypeScript-сцены, спрайтовый player, director, visual physics |

| `src-tauri/` | Tauri/Rust: окно, трей, хоткеи, watchers, single-instance |
| `public/pixel/` | Готовые pixel-art кадры |
| `scripts/` | Генерация/подготовка ассетов |

## Релиз

Версия релиза: `0.2.0`.

Релизный workflow `.github/workflows/build-unix.yml` собирает и прикрепляет:

- Windows: `ECHO-Windows-Setup.exe`, MSI, `ECHO-Windows-Portable.exe`, `ECHO-Corvin.exe`, `ECHO-Dante.exe`;
- Linux: `ECHO-Linux-x86_64.AppImage`, `ECHO-Debian-x86_64.deb`, `ECHO-Fedora-x86_64.rpm`;
- macOS: `ECHO-macOS-Apple-Silicon.dmg` и `ECHO-macOS-Intel.dmg`.

Запуск вручную: GitHub Actions -> **Build Release** -> tag `v0.2.0`.

Запуск тегом:

```bash
git tag v0.2.0
git push origin v0.2.0
```

Перед публикацией проверь `CHANGELOG.md` и `RELEASE_CHECKLIST.md`.

## Приватность

ECHO читает только локальные сигналы: активность AI-логов, факт печати, окна медиа/игр и свои файлы в `~/.echo/`. Он не читает содержимое клавиатурного ввода и не отправляет телеметрию. Секреты для генерации ассетов хранятся в `.env` и не должны попадать в репозиторий.
